A ping and a handshake see the same server very differently.

Uptime monitors only ask whether a URL answers. MCP clients need a real MCP response, so a server can pass every ping and still fail every assistant.

Regular uptime monitor

Toolbeat

expected JSON-RPC, got HTML
Catches the broken handshake

For servers behind a sign-in, Toolbeat also checks that clients get the 401 and sign-in details they need to start OAuth.
